# Synthetic test data only

Every value in this directory is fabricated for detector testing. Do not copy
customer records, employee data, production logs, exported prompts, or live
credentials into these fixtures.

- RRN samples are generated by `scripts/make_rrn_samples.py` with conspicuous
  all-zero serial portions; only the mod-11 checksum math is meaningful.
- Phone and account samples use obvious zero/nine-heavy placeholders.
- Card samples are payment-network test numbers, not usable cards.
- API keys and tokens are nonfunctional examples or random strings created
  solely to exercise format and entropy rules.

Passing these small, synthetic sets measures regression behavior only. It is
not evidence that the detector has the same recall or false-positive rate on
production traffic.
